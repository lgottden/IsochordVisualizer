# Week 9 Report
This week, I worked on producing real-time visualization of MIDI data from a selected MIDI file. I was able to take the scripts and assets from my isochord grid project and integrate them into my Maestro demo project. I then used a function provided in the demo, which simply determines whether a MIDI event has occured, to instantiate a new GameObject (a blue sphere) at the correct note position on the isochord grid whenever a MIDI note is played; these GameObjects are subsequently destroyed after the full duration of the MIDI event. This visualization works in real time, and it is note-accurate; however, it cannot yet display more than one octave, and it cannot further visualize relationships between notes (with triangles, lines, etc.). These limitations make it difficult to accurately visualize the harmonic structures in the music. My goal for next week is just to make this visualization more elaborate, so that some of these harmonic relationships can be more accurately displayed.
