# Week 8 Report
This week, I worked on altering my grid so that it resembled the isochord grids displayed in the Bergstrom paper; I was able to accomplish this by offsetting every other row in the grid by 0.5 units. I then created 12 separate functions that constructed different harmonic structures over the isochord grid (perfect 5th, major 7th, minor 2nd, etc.). These constructions utilize GameObjects (spheres and lines) and triangles constructed using the grid vertices; they each take a root note as input (represented as an integer) and construct the harmonic shape in relation to the position of said root note. I have uploaded a few screenshots of these harmonic structures to this folder. For next week, I would like to work on making a MIDI event handler and using this handler to construct various harmonic shapes in response to MIDI note values.
