# Week 6 Report

This week, I downloaded the Maestro Tool Kit from the Unity Asset Store and worked on implementing it into a new project. I was able to successfully integrate Maestro into the project and open a demo, which played a MIDI file and displayed a GUI allowing the user to change various parameters that manipulated the sound passing through the MIDI synths. I spent a lot of time looking through the demo's codebase in order to figure out how it processes and manipulates the MIDI data. Eventually, I was able to find the class that stores this data, and I wrote a short script that printed all of it to the Unity console at the start of the project. I have added the Maestro project to this folder, as well as some screenshots displaying the MIDI data as it appears in the console.
